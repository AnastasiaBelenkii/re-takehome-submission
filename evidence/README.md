# Archived run evidence

This Git commit is a direct child of generating code commit `16f65f6e963cfe86a9776fe7cf1215e317e11681`. It links 9 archived run provenance record(s) to immutable, public-read object URLs. Large result and transcript artifacts remain in object storage rather than Git.

Queryable catalog: <https://vm-re-takehome-data.sfo3.digitaloceanspaces.com/catalog.json>

See `ARCHIVE_POINTER.json` for per-run provenance URLs, source workers, conditions, problems, and SHA-256 checksums.

This commit also contains 3 unique raw transcript JSON payload(s) under `evidence/transcripts/`; `evidence/TRANSCRIPT_INDEX.json` maps their original archive paths.
