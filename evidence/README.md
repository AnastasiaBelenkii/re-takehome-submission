# Archived run evidence

This Git commit is a direct child of generating code commit `e8af4fb7d278cbf7c5e3e636716a6512f85da140`. It links 56 archived run provenance record(s) to immutable, public-read object URLs. Large result and transcript artifacts remain in object storage rather than Git.

Queryable catalog: <https://vm-re-takehome-data.sfo3.digitaloceanspaces.com/catalog.json>

See `ARCHIVE_POINTER.json` for per-run provenance URLs, source workers, conditions, problems, and SHA-256 checksums.

This commit also contains 56 unique raw transcript JSON payload(s) under `evidence/transcripts/`; `evidence/TRANSCRIPT_INDEX.json` maps their original archive paths.
