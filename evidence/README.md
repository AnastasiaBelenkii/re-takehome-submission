# Archived run evidence

This Git commit is a direct child of generating code commit `73eb36dbe07abfa23141ffbabce4c4d65d7567a8`. It links 149 archived run provenance record(s) to immutable, public-read object URLs. Large result and transcript artifacts remain in object storage rather than Git.

Queryable catalog: <https://vm-re-takehome-data.sfo3.digitaloceanspaces.com/catalog.json>

See `ARCHIVE_POINTER.json` for per-run provenance URLs, source workers, conditions, problems, and SHA-256 checksums.

This commit also contains 94 unique raw transcript JSON payload(s) under `evidence/transcripts/`; `evidence/TRANSCRIPT_INDEX.json` maps their original archive paths.
