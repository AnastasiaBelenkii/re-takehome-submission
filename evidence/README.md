# Archived run evidence

This Git commit is a direct child of generating code commit `e1c8fee0a5dbe1b751cb7dfe8ac3ddf759c51462`. It links 54 archived run provenance record(s) to immutable, public-read object URLs. Large result and transcript artifacts remain in object storage rather than Git.

Queryable catalog: <https://vm-re-takehome-data.sfo3.digitaloceanspaces.com/catalog.json>

See `ARCHIVE_POINTER.json` for per-run provenance URLs, source workers, conditions, problems, and SHA-256 checksums.

This commit also contains 27 unique raw transcript JSON payload(s) under `evidence/transcripts/`; `evidence/TRANSCRIPT_INDEX.json` maps their original archive paths.
