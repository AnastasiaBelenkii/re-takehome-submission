# Collaboration engine v2

This experiment freezes one shared H+D solver and varies only bounded peer-packet
cadence: C0 has none, C1 exchanges once after the first complete dual failure,
and C2 exchanges after every complete dual failure. The original protocol is in
`PLAN.md`; operational changes must only be appended to its deviations section
and `DEVIATIONS.md`.

The checked-in queue has 87 cells: 54 shallow core cells, including the three
sentinel cells; 27 shallow breadth cells; and six deep case-study cells. The
paired seeds and deterministic arm rotation are generated by
`collaboration_engine_v2.experiment.build_queue`. `rmo_2000_6` is excluded as a
declared dataset defect.

Preflight without spend:

```bash
.venv/bin/pytest -q
env -u OPENROUTER_API_KEY bash scripts/smoke_test.sh
```

Paid execution requires an exact clean commit and an explicit confirmation:

```bash
python scripts/control_collaboration_v2.py \
  --commit "$(git rev-parse HEAD)" \
  --state /opt/takehome-results/collaboration-engine-v2/controller.json \
  --results-root /opt/takehome-results/collaboration-engine-v2 \
  --confirm-paid-launch I_UNDERSTAND_THIS_LAUNCHES_PAID_C0_C1_C2_RUNS
```

Raw outputs, validation rechecks, and checksums stay under the external results
root. Compact `SENTINEL.md`, `MORNING.md`, CSV, and JSON matrices are emitted in
its `analysis` directory.
